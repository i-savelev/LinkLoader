# LinkLoader

`LinkLoader` - Revit-плагин для пакетной подгрузки связей из Revit Server в открытый хост-документ.

Плагин:
- позволяет выбрать несколько моделей через `RevitServerBrowser`
- загружает только модели с настроенными общими координатами
- может распределять типы и экземпляры связей по рабочим наборам на основе Excel-конфигурации
- закрепляет (`Pinned`) созданные экземпляры связей
- пишет подробный лог через `RevitLogger`

## Назначение

Команда помогает быстро загрузить набор моделей из Revit Server в текущий проект без ручного создания каждой связи. Основной сценарий:

1. Открыт хост-документ в Revit.
2. Пользователь выбирает модели в окне `RevitServerBrowser`.
3. При необходимости подключает Excel-файл с правилами распределения по workset'ам.
4. Плагин загружает только те модели, у которых обнаружены общие координаты.
5. Для подходящих моделей создаются связь и экземпляр связи, назначается рабочий набор и выполняется закрепление.

## Команда PluginsManager

Плагин регистрируется через статические поля в классе команды:

- `IS_TAB_NAME`: `ISTools`
- `IS_NAME`: `Пакетная подгрузка связей`
- `IS_IMAGE`: `LinkLoader.Resources.LinkLoader.png`

Описание команды в интерфейсе:

> Автор: https://github.com/i-savelev  
> Команда загружает указанные модели из ревит-сервера как связи. Для распределения по рабочим наборам используется конфигурация из excel.

## Как работает

Для каждой выбранной модели плагин:

1. Преобразует путь Revit Server в `ModelPath`.
2. Создаёт `RevitLinkType` и `RevitLinkInstance`.
3. Открывает связанный документ и проверяет наличие общей точки через `OST_SharedBasePoint` и `BasePoint.IsShared`.
4. Если общие координаты не найдены, удаляет созданные связь и тип и пропускает модель.
5. Если подключён Excel-файл, ищет первое правило, у которого шаблон из столбца `A` входит в имя файла модели.
6. Находит или создаёт рабочий набор и назначает его и типу связи, и экземпляру связи.
7. Закрепляет экземпляр связи.

По завершении выводится итог по количеству:
- успешно загруженных моделей
- пропущенных моделей без общих координат
- моделей с ошибками

## Формат Excel

Поддерживается файл `.xlsx` или `.xls`. Используется первый лист.

Структура:

- столбец `A` - часть имени файла модели
- столбец `B` - имя целевого рабочего набора

Чтение начинается со второй строки, первая строка предполагается заголовком.

Пример:

| A | B |
|---|---|
| AR | AR |
| KR | KR |
| OV | MEP_OV |

Логика сопоставления:
- поиск нечувствителен к регистру
- используется первое совпавшее правило
- если совпадений нет, связь остаётся в рабочем наборе по умолчанию

## Логирование

Лог пишется через `RevitLogger` в файл:

`%LOCALAPPDATA%\Temp\i-savelev\LinkLoader.log`

В лог попадают:
- старт команды
- активный хост-документ
- количество выбранных моделей
- чтение Excel и найденные правила
- результат обработки каждой модели
- создание или поиск рабочих наборов
- ошибки, пропуски и итоговая статистика

При критических ошибках дополнительно используется `RevitLogger.DebugWindow`.

## Сборка

Проект собирается как библиотека (`.dll`).

Особенности текущей конфигурации:
- `Debug` собирается в `output_dll/`
- `Release` собирается в `LinkLoader/bin/Release/`
- `RevitAPI` и `RevitAPIUI` подключены из локальной папки `LinkLoader/RevitApi/`
- `RevitLogger` и `RevitServerBrowser` подключены через относительные пути к соседним репозиториям

Перед сборкой проверьте, что рядом доступны зависимости:

- `..\..\RevitLogger\RevitLogger\bin\Debug\RevitLogger.dll`
- `..\..\RevitServerBrowser\output_dll\RevitServerBrowser.dll`

Пример сборки из Visual Studio:

1. Открыть `LinkLoader.slnx`.
2. Восстановить NuGet-пакеты.
3. Убедиться, что внешние DLL доступны по путям из `.csproj`.
4. Собрать проект в `Debug` или `Release`.

## Ограничения и замечания

- Плагин работает только при наличии открытого активного документа-хоста.
- Модели без общих координат не загружаются и удаляются сразу после проверки.
- Проверка общих координат зависит от доступности связанного документа после создания связи.
- Для Excel-правил не используется сложная маска или regex, только поиск подстроки в имени файла.
- В коде используется первый лист Excel без дополнительного выбора пользователем.
