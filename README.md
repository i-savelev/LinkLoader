# LinkLoader

Плагин для пакетной подгрузки связей из Revit Server в открытый хост-документ с гибкой настройкой через Excel.

## Основные возможности
- **Выбор с Revit Server**: интеграция с [RevitServerBrowser](https://github.com/i-savelev/RevitServerBrowser) для удобного выбора моделей без локального копирования.  
- **Фильтр по координатам**: загружает только модели с настроенными общими координатами.  
- **Распределение по рабочим наборам**: автоматическое назначение рабочих наборов для типов и экземпляров связей.  
- **Закрепление**: созданные экземпляры связей автоматически закрепляются.  
- **Подробное логирование**: файл + debug-окно для быстрой диагностики.

## Настройка через Excel
Плагин читает правила из первого листа Excel-файла (`.xlsx` или `.xls`), сопоставляя часть имени файла модели с шаблоном. Поиск нечувствителен к регистру, применяется первое совпавшее правило.

Поддерживаемые колонки:
- **Столбец A**: часть имени файла `.rvt` для привязки настроек (поиск подстроки).
- **Столбец B**: имя целевого рабочего набора (Workset).

*Если совпадений нет, связь остаётся в рабочем наборе по умолчанию.*

| A (Часть имени файла) | B (Рабочий набор) |
| :--- | :--- |
| `AR_` | `AR_Models` |
| `KR_` | `KR_Models` |
| `OV_` | `MEP_OV` |

## Установка
Поддерживаются версии Revit 2022-2026
1. Скачайте или соберите проект или скачайте файлы из папки `output_dll`.
2. Скопируйте **все файлы** из папки `output_dll` в папку, настроенную для [PluginsManager](https://github.com/i-savelev/PluginsManager).

## Запуск и использование
1. Откройте модель Revit.
2. Выберите команду: **Пакетная подгрузка связей**.
3. В появившемся окне `RevitServerBrowser` отметьте нужные модели в дереве.
4. *(Опционально)* Укажите путь к Excel-файлу конфигурации.
5. Нажмите кнопку запуска. 
6. Следите за прогрессом. По завершении итоги и подробный лог будут сохранены в `%LOCALAPPDATA%\Temp\i-savelev\LinkLoader.log`.

## Стек и зависимости
Проект собирается как библиотека **.NET Framework 4.8**.

- [RevitLogger](https://github.com/i-savelev/RevitLogger) — внешняя библиотека для подробного логирования в файл и вывода debug-окна.
- [RevitServerBrowser](https://github.com/i-savelev/RevitServerBrowser) — отдельная библиотека для взаимодействия с Revit Server.
- `EPPlus 4.5.3.3` — для чтения Excel-конфигурации.
